# SuperTokens documentation MCP

Connect the SuperTokens documentation MCP in your coding agent with this endpoint:

`https://supertokens.com/docs/mcp`

The server is read-only and provides `search_docs`, `get_page`, `list_pages`, and `get_navigation`. Search first, then fetch relevant documentation pages. The endpoint is advertised by SuperTokens at `https://supertokens.com/docs/agent-readability.json`.

MCP configuration is client-specific and should be added to the coding agent's MCP settings. This repository reference keeps the official endpoint discoverable without committing machine-specific configuration or credentials.
